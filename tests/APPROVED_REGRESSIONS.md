Use Node 24 and the repository's pinned pnpm with matching native dependencies:

```sh

pnpm --filter @ponderosa/server test:built
```

`pnpm test` builds, typechecks and runs the server/web tests plus packaging qualification tests. No new test dependency is added. The server tests create one fresh synthetic data root per case and use Fastify injection without a network listener. Provider fixtures own inert detached children to exercise actual process identity and shutdown; they do not invoke a subscription or execute shell/file tasks. The attachment reader opens the server-supplied path and verifies file-derived replies. Artifact reading verifies an explicit `ponderosa://artifact/…` reference, rather than assuming catalog presence means readable bytes. Browser manual-control tests exercise the real broker/client over an owned Unix socket with a controlled driver. The local transport tests exercise host-created retained capabilities; they do not bypass the disabled new-pairing HTTP route.

Successful integration roots are removed only after awaited shutdown and observed child exit. Failed roots are retained and printed in diagnostics. Shared/private contexts have distinct markers. Async assertions track new Run IDs or new provider inputs; an older completed Run cannot satisfy a recovery assertion. Draft globals and mocked clocks are restored between tests.

The Decision case completes every child first, so the Decision itself is the remaining blocker. Any/quorum consumption does not fabricate completion or cancel remaining work; ordinary interim reporting preserves the final-delivery obligation. Invalid creation input proves refusal before creating visible state; crash/fault-injection atomicity remains a separate coverage gap. Fixture shutdown awaits roots still opening when an assertion fails and retains the original assertion diagnostic.
