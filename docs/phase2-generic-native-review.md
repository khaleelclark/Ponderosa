# Generic import native closure corrections

Native application receipts originate only from actual shared planner tasks. Metadata-only and data-only roots do not inherit global Git/harness flags or remain falsely applying after success.

Managed live native completion forwards each original staged device/inode identity into the shared helper's held-open check. Replacement between asynchronous precheck and native open is refused before native mutation; original roots and unavailable ownership remain retained.

Final ordinary/native metadata is applied deepest-first, so restrictive parent mode or ACL changes cannot prevent child finalization. Original byte-phase identities remain bound to each finalizer.

Regression source was added to portability.test.mjs and portable-git-recreation.test.mjs. No test/build/typecheck execution occurred in this lane; consolidated validation remains with the parent.

Generic live import now groups folder metadata, originals and membership by source root before allocating or populating. Typed parent/child roots use the existing locally issued contained-root reservations; all source Separate ownership is allocated before native work. A Shared child uses the exact preparing operation to bind its unused managed Project through the same scoped canonical authority. Ordinary public settings cannot override host paths.

All canonical owners stay fenced across regular originals, aliases, native closure and deepest-first metadata. A generic namespace binding failure preserves the original preparing operation and its exact member/path receipts, without rollback or physical replay. Source mode overrides are checked for collapsed/split root membership before mutation.

The authoritative topology validator aggregates all files for each root, so a separate originals owner cannot bypass a nested boundary, local alias target or directory collision check. Added source-only generic-live-roots.test.mjs coverage for split ownership, all supported nested mode pairs, cross-root inode aliases, override refusal and nested boundary refusal.
