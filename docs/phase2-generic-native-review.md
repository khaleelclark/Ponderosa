# Generic import native closure corrections

Native application receipts originate only from actual shared planner tasks. Metadata-only and data-only roots do not inherit global Git/harness flags or remain falsely applying after success.

Managed live native completion forwards each original staged device/inode identity into the shared helper's held-open check. Replacement between asynchronous precheck and native open is refused before native mutation; original roots and unavailable ownership remain retained.

Final ordinary/native metadata is applied deepest-first, so restrictive parent mode or ACL changes cannot prevent child finalization. Original byte-phase identities remain bound to each finalizer.

Regression source was added to portability.test.mjs and portable-git-recreation.test.mjs. No test/build/typecheck execution occurred in this lane; consolidated validation remains with the parent.
