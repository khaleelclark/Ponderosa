# Branch physical working-folder closure

A full Branch package carries one closed working-data graph alongside independent Chat definitions. Import creates canonical Agents through the existing importer, retains every Chat's own history and memory, then restores the physical graph once. It never creates carrier Agents or merges foreign Chat histories.

Recovery folders are chosen explicitly. Typed nested roots retain their captured relative path. Regular originals are written across all roots before links; Git/provider activation follows all aliases, and ordinary/native metadata is finalized last. The byte phase returns original root device/inode custody, reused for links, native recovery and final metadata. Managed Separate roots receive fresh local ownership; source paths cannot grant custody.

The existing installation plan saves the exact physical intent before mutation and retains partial artifacts, normalized diagnostics, per-family application receipts and original inode evidence. Interrupted or uncertain physical phases remain held without replay. A completed receipt may reconstruct missing UI result projections without repeating writes.

Nested Shared Chat roots register in fresh provisional managed namespaces so valid physical graphs do not create logical Chat-registration cycles. Once all canonical owners exist, a scoped internal bind validates a locally issued contained-root receipt, fences every affected owner, verifies exact idle staging/creation receipts, and commits Project, Chat and Shared working-copy paths together. The original creation path remains provenance only; its provisional directory is retained. Existing Projects and ordinary public APIs cannot use this internal path.

Imported originals are published to their exact canonical owners and attached to the existing history archive by byte-stream augmentation. Authored history, source, timestamps and projection offsets are preserved; the canonical incremental package parser/serializer supports large archives without a whole JSON string. An attempted attachment is journaled in the original creation receipt and is not automatically repeated.

Regression sources: tests/branches/working-data-import.test.mjs, tests/organizations/portable-history-json.test.mjs and tests/chats/branch-working-data-files.test.mjs. Implementation first: none were executed in this lane; integrated validation belongs to the parent.

An interrupted final namespace bind retains an exact Project-local intent with the local parent/child inode receipt and Shared owner IDs. Startup may reconcile only those known canonical metadata paths before rebuilding views; it never creates roots or repeats native writes. The outer physical outcome remains incomplete and held.
