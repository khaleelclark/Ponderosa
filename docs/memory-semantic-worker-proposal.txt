Minimal Python rationale
The pinned upstream retrieval machinery and Python PersistentClient share warmed local models without exposing a separate public Chroma server. A JS client alone does not replace the embedding/reranking runtime or native model packaging. Proposed exception is one private supervised Python worker per installation, with TypeScript retaining orchestration, SQLite lifecycle, live authorization and provider integration. It is not one Python process per Agent. A TypeScript-only inference replacement would need a separately qualified model conversion/tokenizer/reranker and would depart from this upstream adaptation; do not quietly substitute it. The next manager task must explicitly authorize the bounded Python/dependency/native stage before provisioning.

Protocol and host lifecycle
Use a versioned, bounded private framed stdio protocol without public MCP/HTTP tools. Worker may embed explicit authorized text, immutable upsert/remove vectors, search a host-selected collection/index generation and rerank a bounded authorized text batch. Host chooses opaque hashed collection names from installation owner/global or canonical Project, never model input. Worker never opens canonical SQLite, assigns ownership, interprets memory instructions, emits Communication, creates Runs, or restores/forgets canonical records.
Proposed initial ceilings: 256 KiB frame, 100 candidate IDs, 20 rerank texts/10,000 codepoints each (total frame cap wins), one running CPU job and queue of 32. Final recall count/token budget/quality and latency thresholds require measurement. Oversized response, malformed IDs, wrong version, cancellation, EOF and worker crash fail closed. Host lifecycle owns the process group, readiness, restart backoff, cancellation deadlines and awaited shutdown; reuse existing native-host supervision. No new Agent scheduler/permission service.

Durable index consistency
Consume the foundation's transactional index intents. Each external vector ID is memoryId:revision:canonicalGeneration:modelIndexGeneration. Hydrate/revalidate live ownership, revision, lifecycle, expiry and tombstone before indexing, returning or reranking. Rerank only current authorized text; revalidate again after asynchronous responses before return/provider submission. Reordered/deleted responses cannot supersede current SQLite. Remove exact immutable IDs, never broad delete-by-memory races. A consumer needs a bounded cursor/lease/ack record and deterministic idempotent upserts; design that only when implementing the worker, without inventing a second event log. Rebuild in a fresh model/index generation and switch only after authoritative validation. Pending/failed semantic index never undoes committed saves; direct get remains immediate. Existing FTS mutation failure remains transactional rollback and must be distinguished from semantic outage after commit.
Scope cache/session invalidation must combine canonical memory generation, global grant revision, effective restriction changes and source visibility/expiry. No context already submitted to a provider can be retroactively erased. Startup/reseed/recovery/exposure manifests remain a later integration gate.

Native/offline packaging gates
Build an isolated installation-owned runtime; never use an operator/provider profile/global Python or pip tree. Provision only with explicit authorization, hash-verify all bytes and generate a complete platform-specific transitive resolver lock plus license SBOM. Candidate root pins above are exact; complete transitive lock and runtime executable hashes are NOT complete and block installation-ready status. CUDA/NVIDIA dependency branches are prohibited for the CPU package; inspect the CPU wheel's actual metadata rather than relying on regular PyPI torch dependencies. ONNX Runtime's selected manylinux wheel requires glibc 2.27/2.28 despite Chroma's older wheel tag, so qualify the effective baseline. No macOS/Windows candidate artifact lock/qualification is supplied; those require exact per-platform wheels/runtime/model manifests, native lifetime tests and portable path/locking behavior before support is claimed.
Set HF_HUB_OFFLINE=1, TRANSFORMERS_OFFLINE=1, HF_DATASETS_OFFLINE=1, HF_HUB_DISABLE_TELEMETRY=1, DO_NOT_TRACK=1 and ANONYMIZED_TELEMETRY=False before imports. Explicitly disable Chroma telemetry; do not rely solely on environment flags. Refuse missing/corrupt model/module/tokenizer artifacts instead of downloading. Use one private installation-specific cache/index folder and host-selected local paths; no trust in Agent-provided collection/path or model code. A local worker is an installation boundary, not isolation from Agents already able to execute arbitrary host shell code.

Reproducible acceptance/independent review before enabling semantic mode
1. Verify every wheel/runtime/model hash and license against the committed complete lock; rebuild offline from the bundle in a clean Linux x86_64 fixture. Record OS/glibc/CPU/RAM/disk, exact versions, binary/model hashes and bundle size. Repeat separately on each claimed native platform.
2. Run with network-deny tracing before imports and during load/embed/rerank/search/restart; assert zero outbound connects and no telemetry. Remove a model/tokenizer module and corrupt a weight: no network, bounded unavailable result, normal Runs and direct canonical reads continue. Confirm no cuda libs/GPU requirement.
3. Exercise supervised startup/EOF/crash/restart/disk-full/queue overflow/malformed frames/timeouts/cancellation and awaited process-group teardown. An uncertain teardown blocks unsafe replacement. Worker cannot open canonical store or public provider tools.
4. Hold a worker response, revoke a global grant/change policy/forget/expire/delete Project, then release response: no stale/unauthorized text or source metadata returns. Replay/reorder v1/v2/delete index intents across process exit; stale vectors never hydrate. Existing grant/content generations win, not index scores.
5. Use 20–30 labeled fixtures including exact terms, paraphrases, contradictory current sourced records, unrelated Projects and no-match queries. Measure lexical and semantic recall@5/precision@5 separately, zero unauthorized/stale returns, weak-brief rate, p50/p95 startup/index delay, queue latency, CPU/RAM and actual provider input token cost. Thresholds are not approved or measured yet.
6. After startup/reseed/UI integration, use separately authorized real subscription-backed Codex and Claude Runs: save, fresh other-provider recall, correct, forget, confirm other Project cannot retrieve. Mocked/transport fixtures in this host stage do not prove that workflow.

Open gates
Complete transitive hash lock/license SBOM/runtime packaging; authorized Python exception/provisioning; actual semantic worker/intents consumer; recall quality and offline/native performance; exact source declassification/revision/document binding; startup/reseed exposure tracking and UI; old SQLite restore deletion/grant ledger completeness. No installation-ready, semantic-ready or release-ready claim.
